# Nest SSH (historical)

Nest-plane SSH as a free Hatchery product was removed from free HEAD ([#620](https://github.com/dustinestes/Hatchery/issues/620), [ADR-0044](adr/0044-free-head-local-nest-only.md)).

| Plane | Status |
|---|---|
| **Guest remoting** (SSH/WinRM to known guest VMs) | Free - [guest transport](guest-transport.md), remoting identities |
| **Remote Nest hierarchy** | Hatchery Enterprise via Nest Agent ([#345](https://github.com/dustinestes/Hatchery/issues/345)) - see [Enterprise docs](enterprise/README.md) |

Do not follow older Nest SSH onboarding for free Controllers. Local Nest registry: **Nests → Connections**.
